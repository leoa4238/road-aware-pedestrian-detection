## 연구 방향

- 바뀐 것: "도로 정보로 보행자 탐지 성능 향상(RGA)"에서 **"생활도로 위험 보행자 판별(RCR-Head)"** 로 전환을 검토 중이다. 교수님 승인 전이다.
- 근거 1: RGA는 탐지에 도로 정보를 쓰지 않았다. 마스크를 지워도 보행자 AP가 0.0008만 변했다 (`docs/RGA_IMPLEMENTATION.md`).
- 근거 2: 파일럿에서 도로 맥락이 위험 판별에 도움이 되었다 (아래 4절).
- 교수님 보고 자료: Claude Docs "연구 방향 변경 보고" (사용자 계정).

## 파일럿 결과 (연구자 v0 라벨 113명, 세션 단위 5-fold × 20회)

| 방법 | macro-F1 | 위험 재현율 |
|---|---:|---:|
| 규칙: 발이 도로 위면 위험 | 0.37 | 0.52 |
| 위치만 (고정 경로 띠 기준) | 0.38 | 0.57 |
| 도로 마스크 맥락만 | 0.57 | 0.79 |
| 위치 + 도로 마스크 | 0.52 | 0.64 |

- 도로 맥락이 판별에 도움이 된다. 단순 규칙으로는 부족하다.
- 고정 경로 띠는 실제 경로를 잘 못 잡는다(AI 초안의 "경로 안" 39명 중 21명이 띠 밖). 도로 모양에 맞춘 경로 추정이 필요하다는 근거다.
- 표본이 작아 예비 결과로만 본다.
