## 6. 도로 경계 가설의 판정

새 경계 근접 기준은 `abs(signed_distance) / bbox_height <= 0.25`다. 도로 내부는 음수, 외부는 양수로 정의했다. 기존 `road_dist_norm`은 발 주변 창에서 도로 영역까지의 거리여서 경계 거리로 재사용하지 않았다.

| 집단 | GT | FN | 미탐률 |
|---|---:|---:|---:|
| 추정 경계 근처 | 1,106 | 169 | 15.28% |
| 추정 경계에서 먼 곳 | 241 | 122 | 50.62% |

근처-먼 곳 미탐률 차이는 **-35.34%p**였다. clip 단위 bootstrap 95% 구간은 **[-44.23, -26.61]%p**, 상위 주행 세션 단위 구간은 **[-43.51, -26.94]%p**다. 크기별 층화와 지지점 보조 분석에서도 대체로 같은 방향이었다.

**현재 정의와 기존 고정 분할에서 "경계 근처에서 미탐이 더 많다"는 가설은 지지되지 않았다. 따라서 이 결과를 경계 유도 어텐션의 필요성이나 성능 향상을 입증한 근거로 쓰면 안 된다.**

이것이 모든 도로 맥락 활용이 무의미하다는 뜻은 아니다. 마스크는 추정치이며, 도로/비도로 경계에는 사람과 차량에 생긴 분할 구멍도 포함된다. 640px 마스크의 픽셀 거리는 실제 연석, 3차원 거리, 미터 단위 거리가 아니다. 사람이 마스크와 발 기준점의 정확성을 확인하기 전에는 물리적 경계 효과로 해석할 수 없다.

## 7. 데이터 문제와 평가 제한

1. **상위 주행 세션의 교차 분할:** 하위 clip 중복은 0개지만, 상위 주행 세션 99개가 여러 split에 걸친다. 관련 메타데이터 행은 5,501개다. 현 평가를 독립적인 새 주행 세션에 대한 일반화 검증으로 주장하지 않는다.
2. **train 파일명 충돌:** `CK_A01_R03_erh_rainy_01023394_F`가 서로 다른 clip에 중복된다. 메타데이터 이미지는 5,501행인데 디스크 이미지는 5,500개다. 해당 이미지의 객체 수가 메타데이터와 라벨 사이에서 다르며, 백업만으로 어떤 원본이 남았는지 확정할 수 없다.
3. **좌표 점검:** 비교 가능한 라벨에서 0.01px 초과 좌표 차이는 0개다. 객체 수 불일치 이미지 1개는 이 비교에서 제외되므로 전체 정합성의 완전한 증명은 아니다. test 분석을 막는 중복 정답 문제는 보고되지 않았다.
4. **분할 마스크와 검수:** road/sidewalk/other 분류는 추정값이다. 검수 없이 정답 또는 위험 라벨로 사용하지 않는다.
5. **시험 자료의 개발 사용:** 이번에 확인한 test 조건은 후속 가설 생성에 이미 사용했다. 이후 모델을 이 결과에 맞춰 개발한다면 최종 독립 평가 자료를 별도로 확보해야 한다.

원본 분할, 이미지, 라벨은 자동으로 수정하지 않았다. 세션 bootstrap은 집단 내 상관을 고려하는 민감도 분석일 뿐, 학습/시험 세션 공유 문제를 제거하지 않는다.

## 8. 다음 작업 순서

### 우선 1: 사람이 마스크 150개 검수

`mask_review_sheet.csv`의 `overlay` 경로로 이미지를 확인하고 아래 빈 항목을 채운다.

- `human_true_zone`: 원본에서 판단한 road/sidewalk/other. 불확실하면 unknown으로 기록한다.
- `human_mask_correct`: 추정 마스크와 발 위치 영역 판단의 적절성. 판단 기준을 먼저 고정하고 동일하게 적용한다.
- `human_note`: 발 기준점 부정확, 사람/차량 분할 구멍, 경계 판단 불가 등의 근거.

이는 자동 정답이 아니라 사람의 탐색적 검수다. 검수 표본은 추정 영역별 50개 객체씩이며 모집단 오류 비율의 대표 표본으로 단정하지 않는다. AI가 이미지 일부를 살펴보는 것과 사람의 확정 검수는 구분한다.

### 우선 2: 데이터 정리의 전제 해결

원천 이미지와 JSON으로 train 충돌 1건을 확인한다. 이후 `(session, clip, filename)` 키와 상위 주행 세션 분할을 사용하는 **새 데이터 버전**을 설계한다. 기존 자료를 덮어쓰지 않고, 실제 분할 변경과 재학습 전에는 사용자 확인을 받는다.

### 우선 3: 모델 기여 가설을 좁혀 결정

경계 근접 실패를 전제로 바로 RGA를 구현하지 않는다. 현재 확인한 작은 객체 실패와 부정확한 도로 prior 문제를 바탕으로, 도로 맥락이 어떤 조건에서 유효한지 검증할 설계를 먼저 정한다.

후보는 잘못된 도로 마스크가 원래 탐지 특징을 지우지 않도록 하는 residual attention이다. 비교 대상은 기존 YOLO, 단순 road 입력, 동일 용량 일반 attention, RGA, RGA+경계다. 동일 입력/학습/시드 조건과 별도 평가셋을 확보한 뒤 보행자 AP, 재현율, 오탐, 크기별 성능, 마스크 오류 민감도와 속도를 평가한다. 아직 이 구조의 독창성이나 개선 효과는 확인하지 않았다.

동일 설정에서는 기존 예측 캐시를 재사용한다. 임계값, 가중치, 추론 설정을 바꾸면 별도 출력 폴더에 결과를 저장한다. 위 명령은 새 탐지 모델을 학습하는 명령이 아니다.

## 10. 다른 AI 또는 교수님께 전달할 요약

> 기존 YOLO 보행자 탐지의 실패 조건을 분석하기 위해 최종 가중치 성능 재현, 원본 좌표 일대일 매칭, 조건별 통계와 데이터 감사를 수행했다. 추정 도로 경계 근처의 미탐이 더 많다는 처음 가설은 지지되지 않았다. 대신 작은 보행자(32~64px, 재현율 0.41)의 미탐이 두드러졌고, 미탐의 44%는 모델이 정답 위치에 후보를 냈지만 점수가 낮아 제거된 경우였다. 임계값을 낮추면 미탐 1개를 회복할 때마다 저점수 박스가 약 6개 늘어나므로, 병목은 후보와 배경의 구분이다. 이에 따라 도로 맥락으로 이 구분을 돕는 residual 어텐션 모듈을 제안하고, 일반 어텐션 등과 같은 조건에서 비교하려 한다. 또한 주행 세션이 split 사이에 섞인 문제를 발견해 세션 단위의 새 split을 만들었고, 이후 모든 모델은 이 split에서 학습한다. 기존 SG-PRR 실험 및 논문은 보존했으며, 새 탐지 모델은 아직 학습하지 않았다.
